
# FlowDocs

AI-powered contract intelligence and workflow management.

FlowDocs helps teams upload contracts, extract important contract information using AI, review and approve extracted data, and track contract renewal tasks.

## MVP Features

- Organization-based access and role permissions
- Secure PDF upload and storage
- AI-assisted contract data extraction
- Human review and approval
- Automatic contract expiry review tasks
- Audit history for important actions

## Technology Stack

- Next.js with App Router
- TypeScript and React
- PostgreSQL and Prisma ORM
- Clerk authentication
